1. 비누제조기가 뭔가요?

환자와 나눈 대화(녹음·녹취록·메모)를 넣으면 AI가 SOAP 노트로 바꿔주고, 원하면 약속처방 세트에서 처방까지 골라주는 웹앱입니다. 서버가 없습니다 — 브라우저 하나로 끝나고, API 키와 프로필은 내 PC에만 저장됩니다.

✅ 8개 회사 + OpenRouter 20종 = 50여 개 AI를 동시에 돌려서 비교
✅ S·O·A·P 단락별 복사 버튼 → EMR 칸에 한 단락씩 붙여넣기
✅ SOAP 먼저, 처방은 💊 처방도 알려줘 버튼을 눌렀을 때만
✅ 내 약속처방 세트 · 구비약물 · 진료 철학 반영
✅ MRI/CT 캡처 첨부 → 영상 인식 모델이 O·A에 반영
✅ 각 모델 옆에 SOAP 1회 예상 비용(≈₩) 표시

3. 진료실 실제 흐름 — 녹음에서 EMR까지

  1. 🆕 새 환자 버튼 — 이전 환자 텍스트·MRI·결과 싹 지움 (키·프로필은 유지)
  2. 🎙 녹음 탭 → 큰 원 버튼 탭 → 진료 → 다시 탭 (기본 7분 자동종료, 30초 전 카운트다운)
  3. Groq Whisper Turbo가 3~5초 안에 텍스트로 → 🧼 자동 SOAP이 켜져 있으면 바로 변환까지
  4. 카드에서 마음에 드는 모델 결과 골라 S 복사 → O 복사 → A 복사 → P 복사 (라벨 없이 본문만, 항목당 한 줄)
  5. 처방이 필요하면 💊 처방도 알려줘 → 약속처방 세트에서 골라 표로 → 메트로엔 코드 보고 직접 입력

💡 녹음할 때 "보존치료 두 달 했고, 주사 두 번, 엄지발가락 힘 4점" 처럼 기간·횟수·등급을 입으로 말해두면 A에 심사 논거 문장이 자동으로 만들어집니다. 말 안 한 건 AI가 지어내지 않습니다 (7장).

6. 약속처방 세트 & 💊 처방 버튼

기본 실행은 SOAP만 만듭니다. 처방 프롬프트 자체를 보내지 않아서 빠르고 쌉니다. 처방이 필요할 때 카드의 💊 처방도 알려줘를 누르면 그 모델이 등록된 세트에서 이 환자 것을 골라 표로 보여줍니다. 세트가 없으면 등록하라고 알려주고 멈춥니다.

세트 등록 형식

## 세트명 | 적응증(언제 쓰는지) | 제외조건(선택)
처방코드	처방명	급여	수량	단위	횟수	日	용법코드	용법

## 요통-신경병증 기본 | 요추 HNP/협착 + 방사통, VAS 5-7 | 신부전, 75세 이상 감량
M1119147	가벨린정75mg	Y	1	T	2	7	PC	식후30분
M1232263	케이캡정25mg	Y	1	T	1	7	AC	식전
  • 빈 줄로 세트 구분, 탭 또는 |로 열 구분, 모르는 칸은 비워둠
  • 가장 확실한 방법: 메트로 이전처방 화면에서 행을 복사해 이 칸에 붙여넣기. 메트로 형식(0 | | 코드 | 처방명 | …)을 자동으로 알아보고 등록형식으로 바꿔줍니다. 위에 ## 세트명 | 줄만 얹으면 끝. 코드가 메트로 것 그대로라 AI가 헛코드를 낼 수 없습니다.
  • 📥 엑셀 양식 받기 → 채워서 📁 파일 선택으로 올려도 됩니다.

처방 표에서 할 수 있는 것

  • 셀 클릭해서 수정, 체크 해제로 행 제외
  • ⌨ 코드 입력용 복사 — 코드·처방명·수량·횟수·日·용법 (매크로용, 9장)
  • 📋 표 TSV / 📋 코드만 / 📊 엑셀 (메트로 열 순서 시트 포함)
  • 노란 행 = 세트에 없는 원외 항목. 비고에 "확인필요"가 뜨면 신기능·알레르기 같은 정보가 없어서 AI가 판단을 보류한 것

7. SOAP이 이렇게 나옵니다 (v40 작성 규칙)

단락규칙
S한글. 진단·계획에 걸리는 진술만. 인사·보험·잡담·반복 삭제. 과거력·알레르기·약물은 구체적으로 있을 때만 — "없음/불명/확인 안 됨" 줄은 절대 안 씀. CC:·HPI:·PMHx: 같은 소제목 없음.
O영어 의학용어 전용. SLR Rt (+) 30°, motor G4/5 Rt EHL, MRI L4-5 central HNP with Rt L5 root compression. 쓸 게 없으면 헤더만. "검사 안 함/소견 없음" 같은 문장 금지.
A병명 딱지가 아니라 진단 + due to 원인 + consistent with 소견 인과 문장. 그리고 형이 말한 사실이 있으면 심사관이 읽는 논거 한 줄: 수술 적응(보존치료 기간·무반응, 이전 주사, 근력 등급, 영상-증상 일치, 기능 제한), MRI 적응(신경학적 징후 동반 방사통, red flag, 6주 이상 보존치료 불응), 시술(레벨·측·실패한 이전 단계). 말 안 한 사실은 지어내지 않음.
P오더 수준만: 약 이름/계열, 검사, 시술(레벨·측), F/U. 용량·횟수·일수·용법 없음 — 그건 💊 처방 표에서.
공통항목당 한 줄, 단락 사이 빈 줄, 불릿·번호·별표 없음, 면책·"의사 확인 요망" 류 문구 없음. 복사하면 EMR에 그대로 줄이 떨어짐.

간략 / 보통 / 상세 세 단계와 영어위주 / 한영병기(A·P에 한글 병기)를 고를 수 있습니다. O는 어느 모드든 영어.

9. EMR(메트로) 연동 — 되는 것, 안 되는 것

결론부터: 메트로 처방창에 Ctrl+V로 처방을 넣는 건 안 됩니다. 2026년 9월 실제 시험 결과입니다.

  • 메트로 처방N 그리드는 글자를 붙여넣어도 화면에만 칠해질 뿐 내부 처방 행이 생기지 않습니다. E 체크박스도 안 먹고 F5 등록도 "선택된 처방 없음". 다중행 붙여넣기 자체가 없습니다.
  • 손으로 코드를 치고 Enter를 누르는 것만 약품 조회를 태웁니다.
  • 그래서 SOAP 텍스트는 단락별 복사 → 차트 칸 붙여넣기(잘 됨), 처방은 표를 보고 직접 입력이 현재 표준 흐름입니다.
  • 키 입력 매크로(AutoHotkey)는 만들어 두었으나 병원 PC 권한(관리자 실행) 문제로 검증하지 못했습니다. 다시 시도할 때는 AHK를 관리자 권한으로 실행하는 것부터 확인해야 합니다.
  • 자주 쓰는 세트는 메트로 자체 약속처방 탭에 등록해 두는 게 가장 빠릅니다. 비누제조기는 "세트 3번 + 케이캡 추가"라는 결론을 주는 역할.

11. 자주 묻는 질문

Q: 모델을 체크했는데 "빈 응답"이 나와요

추론(reasoning) 모델이 생각만 하다 토큰을 다 쓴 경우입니다. v39~40에서 Cerebras·Groq·DeepSeek·Grok·OpenRouter 전부 추론을 낮추거나 껐고, Cerebras Qwen은 자동 재시도합니다. 그래도 나오면 그 모델은 빼고 다른 걸 쓰세요.

Q: Grok 4.6이 너무 느려요

정상입니다. 추론을 끌 수 없는 모델이라 low로 낮춰도 10초 안팎. 일상 SOAP은 Grok 4.1 Fast(₩1.2)나 DeepSeek Flash로.

Q: "Your prepayment credits are depleted"

Gemini 선불 크레딧 소진. ai.studio/projects 에서 충전. DeepSeek·OpenAI도 잔액 소진 시 비슷한 문구가 뜹니다.

Q: "The model does not exist"

모델이 폐기된 것. 목록은 9월 기준으로 정리했지만 AI 회사들이 두 달에 한 번씩 갈아치웁니다. Custom 모델 칸에 새 ID를 넣어 쓰세요.

Q: 환자 데이터가 저장되나요?

이 앱은 아무것도 저장하지 않습니다. 텍스트는 선택한 AI 회사 API로 전송돼 SOAP이 만들어지고 끝. 새 환자 버튼이나 새로고침이면 사라집니다. 녹음 파일도 변환 직후 삭제. 다만 어느 AI 회사에 보내는지는 본인이 고르는 것이니, 병원 정책에 맞는 회사만 체크하세요. 식별정보(이름·주민번호·연락처)는 애초에 넣지 않습니다.

Q: 다른 의사에게 주소를 알려주면 내 API 키가 새나요?

아닙니다. 키는 각자 PC 브라우저(localStorage)에만 저장됩니다. 서버가 없으니 어디로도 전송되지 않습니다. 단, 같은 PC·같은 브라우저를 공유하면 키도 공유되니 Chrome 프로필을 나누세요.

Q: 아내(가정의학과·요양병원)도 쓸 수 있나요?

네. 진료과 프리셋에 가정의학과가 있고(욕창·연하·낙상·다약제 검토 지시 포함), STT 의학용어 사전도 과별로 바뀝니다. 본인 PC에서 키만 따로 넣으면 됩니다.

Q: 뤼튼 같은 국산 무료 AI는?

뤼튼은 개발자 API가 없어서 외부 앱에서 못 씁니다. 대신 업스테이지 Solar Pro 4(한국)가 OpenRouter에 있습니다 — ₩1 미만.
