0. 🌸 Personal — Nari 실시간 자막 · 환자 설명 음성

공용판(v44)과 다른 점은 딱 셋입니다. ① 음성인식이 Nari(Qwen3-ASR)로 말하는 동안 자막이 뜨고, ② SOAP 결과를 환자용 쉬운 한국어로 바꿔 Nari 목소리로 읽어주며, ③ 그러려면 PC에 작은 중계 프로그램(bridge.py)이 켜져 있어야 합니다. 나머지(모델·프로필·영상 판독·이미지)는 공용판과 같습니다.

왜 중계 프로그램이 필요한가

Nari 음성인식은 인증이 붙은 WebSocket 스트리밍 전용이라 브라우저(GitHub Pages)가 직접 붙을 수 없습니다. 그래서 진료실 PC 안에서만 듣는 손바닥만 한 중계가 녹음을 Nari로 흘려보내고 자막을 돌려줍니다. Nari 키는 중계만 알고 브라우저·GitHub 어디에도 가지 않습니다. 중계는 127.0.0.1(이 PC 안)에서만 듣고 요청마다 임의 토큰을 검사하며, 음성·텍스트·키를 로그에 남기지 않습니다.

처음 1회 (10분)

순서할 일
1Python 3.10+ — python.org에서 설치. 설치 첫 화면 맨 아래 "Add python.exe to PATH" 체크. (이미 있으면 건너뜀)
2이 폴더(SOAP_Personal_v45)를 바탕화면 등 평범한 곳에 통째로 둠. 압축 안에서 실행하면 안 됩니다.
3app.narilabs.com → API Keys → 키 생성 · 복사. (신규 계정 $20 크레딧)
4start_windows.cmd 더블클릭 → 첫 실행은 1분(라이브러리 설치) → 키 붙여넣기 → Y (nari.key 파일에 저장, 다음부턴 안 물어봄) → 브라우저가 http://127.0.0.1:8765로 자동으로 열림.
5이 주소는 GitHub Pages와 저장소가 달라 API 키·프로필이 비어 있습니다. 평소 쓰던 페이지에서 🔑 카드의 📤 설정 내보내기 → 이 페이지에서 📥 설정 가져오기. 30초.

🎙 실시간 자막 사용

🗣 환자 설명 음성 (TTS)

SOAP 결과 카드 오른쪽 위 🗣 환자 설명 → 그 모델이 SOAP을 진료실에서 환자에게 말하듯 쉬운 한국어 300~600자로 다시 씁니다(영문 약어 금지, "L4-5" → "허리 네 번째와 다섯 번째 뼈 사이"). 내용은 수정 가능. 🔊 듣기로 Nari 목소리로 재생, 💾 WAV 저장으로 파일(환자에게 카톡·문자로). SOAP에 없는 사실은 안 만들고 약 용량은 말하지 않습니다.

목소리는 왼쪽 🌸 Nari 음성 카드에서 — 한국어(🇰🇷) 목소리가 앞에 오고 자동 선택됩니다. 🔈 테스트로 미리 들어보세요. 요금은 표준 $5/1M자 → 500자 ≈ ₩3.5. Fast($10)는 실시간 대화용이라 여기선 이득 없음.

1. 비누제조기가 뭔가요?

환자와 나눈 진료 내용(타이핑·녹음·녹취록·파일)을 넣으면 AI가 SOAP 노트 초안을 써 주는 웹앱입니다. 내과·정형외과·일반외과·신경외과·마취통증의학과·영상의학과·가정의학과·재활의학과 — 진료과를 고르면 그 과에 맞는 작성 규칙과 의학용어 사전으로 바뀝니다.

✅ 서버가 없습니다. 브라우저 하나로 끝나고, API 키와 프로필은 내 PC 브라우저에만 저장됩니다
✅ 입력은 세 가지 — ⌨️ 타이핑·붙여넣기 · 🎙 실시간 마이크 · 📁 문서·음성 파일
✅ X-ray·CT·MRI·초음파·내시경·사진을 올리면 👁 모델이 판독해 O·A에 반영
✅ 결과는 S·O·A·P 단락별 복사 버튼 → EMR 칸에 한 단락씩 붙여넣기
✅ 여러 AI를 동시에 돌려 비교 · 모델 옆에 SOAP 1회 예상 비용(≈₩) 표시
✅ 환자 설명용 그림은 원할 때만 (기본은 생성 안 함)

AI 결과는 초안입니다. 검토·수정 후 EMR에 입력하세요. 최종 의무기록의 책임은 작성 의사에게 있고, 이 소프트웨어는 의료기기가 아닙니다 (11장).

2. 시작하기 (처음 1회, 5분)

① 접속

https://guricentral.github.io/soap/
Chrome · Edge 권장. 즐겨찾기 해두세요. 마이크 녹음은 이 주소(HTTPS)에서만 됩니다.

② API 키 입력

API 키는 AI 회사가 발급하는 비밀번호입니다. 회사 홈페이지에서 발급받아 앱의 🔑 칸에 붙여넣으면 ✓ 표시가 뜨고 끝입니다. 전부 넣을 필요 없습니다.

키발급처이걸로 되는 것추천

  2. 왼쪽 메뉴 Get API key → Create API key
  3. AIza... 로 시작하는 키 복사 → 비누제조기 Gemini 칸에 붙여넣기

③ 진료과 선택 → 💾 저장

🩺 설정 ② 카드에서 진료과 드롭다운을 고르면 전공·환자군·특별 지시사항이 자동으로 채워집니다. 필요하면 고치고, 진료 철학·자주 쓰는 약제를 적은 뒤 💾 저장. 이후엔 자동으로 불러오고 설정 카드는 접혀 있습니다.

  • 🏥 구리센트럴 원내 약품목록 버튼 — 원내 약품을 효능군별로 약제 칸에 넣어 줍니다. P에서 약을 고를 때 이 목록을 우선합니다. 목록이 길면 AI 호출 비용이 조금 늘어나니, 내 과에서 안 쓰는 효능군은 지워도 됩니다
  • 📁 내 파일 — txt·csv·xlsx로 만든 내 약제 목록을 올려도 됩니다

④ 첫 변환

  1. ① 카드에서 ⭐ 추천 버튼 (키가 있는 가성비 모델 2개가 체크됩니다)
  2. ② 카드 ⌨️ 탭에 진료 내용 입력 — 처음엔 ① 카드 오른쪽 예시 입력으로 내 과 예시를 넣어 보세요
  3. 🧼 SOAP 변환 시작 (Ctrl+Enter)
  4. 결과 카드에서 📋 S 복사 → EMR S칸 … 순서로 붙여넣기

3. 진료실 흐름 — 입력에서 EMR까지

  1. 🆕 새 환자 — 이전 환자의 입력·영상·결과를 싹 지웁니다 (키·프로필은 유지). 맨 위, 변환 버튼 아래, 화면 왼쪽 아래 어디에나 있습니다
  2. ② 진료 내용 — ⌨️ 타이핑·붙여넣기 / 🎙 마이크 / 📁 파일 중 편한 것으로 (4장)
  3. ③ 영상·사진이 있으면 첨부 (선택, 8장)
  4. 🧼 SOAP 변환 — 체크한 AI들이 동시에 씁니다. 마이크는 "끝나면 바로 SOAP"이 켜져 있어서 녹음 종료 → 음성인식 → SOAP까지 자동
  5. 마음에 드는 카드에서 S 복사 → O 복사 → A 복사 → P 복사 (라벨 없이 본문만, 항목당 한 줄). 📋 전체 복사는 네 단락을 빈 줄로 구분해 한 번에
  6. EMR 차트 칸에 붙여넣고 검토·수정. 처방은 EMR 처방창(약속처방 탭)에서 직접 입력 — SOAP의 P는 약 계열·검사·시술·F/U 같은 오더 수준까지만 씁니다

💡 녹음하거나 적을 때 기간·횟수·수치·등급을 말해두면 ("약 두 달 썼는데 효과 없고, 주사 두 번, HbA1c 8.2, 근력 4점") A에 심사관이 읽는 논거 문장이 만들어집니다. 말 안 한 건 AI가 지어내지 않습니다 (10장).

4. 진료 내용 입력 3가지

탭이럴 때방법
⌨️ 타이핑 · 붙여넣기메모를 치거나, 클로바노트 등 다른 앱의 녹취록·EMR 텍스트를 가져올 때입력란에 쓰거나 붙여넣기 → Ctrl+Enter. 길이(간략/보통/상세)와 언어(영어위주/한영병기)도 여기서 고릅니다
🎙 실시간 마이크진료하면서 그대로 녹음할 때엔진 하나 선택(기본 Gemini) → 큰 원 버튼 → 진료 → 다시 버튼. 기본 7분 자동종료(30초 전 카운트다운), 끝나면 음성인식 → SOAP까지 자동. 마이크는 9장
📁 문서 · 음성 파일휴대폰 녹음기·회의 녹음 파일, 또는 txt·csv 문서가 있을 때파일 하나 선택. 텍스트 문서(txt·md·csv·rtf)는 바로 입력란으로, 음성·영상(m4a·mp3·wav·mp4 등, 25MB)은 음성인식을 거쳐 입력란으로 들어갑니다

PDF · Word 파일은 직접 올릴 수 없습니다. 파일을 열어 내용을 복사한 뒤 ⌨️ 탭에 붙여넣으세요. 환자 성명·주민번호·연락처 같은 식별정보는 어느 탭에서도 넣지 않습니다.

5. 진료과별 사용법

진료과를 고르면 세 가지가 바뀝니다 — ① AI에게 주는 작성 규칙(O에 뭘 적을지, A에 어떤 논거를 쓸지), ② 음성인식 의학용어 사전, ③ 입력란 예시. 아래 "말해 두면 좋은 것"을 녹음·메모에 넣으면 A의 논거 문장이 훨씬 좋아집니다.

진료과프리셋이 시키는 것말해 두면 좋은 것
💊 내과검사 수치는 값·단위 그대로, 이전 값과의 추이. 약물 조절 이유. 진단에 조절 상태·병기 포함HbA1c·Cr·eGFR·LDL 같은 수치와 이전 값, 복용 중인 약과 바꾸는 이유, 혈압
🦴 정형외과골절은 분류(AO/Weber/Garden)와 전위, 관절은 ROM 수치·특수검사·K-L 등급. 수술 적응이면 근거ROM 각도, McMurray·Lachman 같은 검사 결과, K-L grade, 보존치료 기간과 반응, 주사 횟수

12. 자주 묻는 질문

Q: 무료로 쓸 수 있나요?

OpenRouter의 Ling 3.0 Flash Santé는 무료이고 Gemini도 무료 구간이 있습니다. 다만 무료 구간은 입력 내용이 모델 학습에 쓰일 수 있는 조건이라 진료 데이터엔 권하지 않습니다. 유료로 써도 DeepSeek Flash 기준 하루 40명에 50원 안팎이니(6장) 결제 등록하고 쓰는 게 맞습니다.

Q: 모델을 체크했는데 "빈 응답"이 나와요

추론(reasoning) 모델이 생각만 하다 토큰을 다 쓴 경우입니다. DeepSeek·Grok·OpenRouter는 추론을 낮추거나 꺼 두었지만, 그래도 나오면 그 모델은 빼고 다른 걸 쓰세요.

Q: Grok 4.6이 너무 느려요

정상입니다. 추론을 끌 수 없는 모델이라 10초 안팎. 일상 SOAP은 Grok 4.1 Fast나 DeepSeek Flash로.

Q: "Your prepayment credits are depleted" / 429 / quota

선불 크레딧 소진 또는 무료 한도 초과. Gemini는 aistudio → Billing, DeepSeek·OpenAI는 각 사이트에서 충전.

Q: "The model does not exist"

모델이 폐기된 것. 목록은 2026년 9월 기준이지만 AI 회사들이 자주 갈아치웁니다. ① 카드 아래 "목록에 없는 모델 직접 추가"에 새 ID를 넣어 쓰세요.

Q: 영상만 올렸는데 오류가 나요

👁 없는 모델(DeepSeek V4 Pro 등)을 체크한 경우입니다. 👁 표시된 모델을 고르세요. 영상 파일이 DICOM이면 캡처해서 png/jpg로.

Q: 마이크 상태줄에 "키 없음"이 떠요

고른 음성인식 엔진의 키가 없는 것입니다. Gemini 엔진이면 Gemini 키, GPT 엔진이면 OpenAI 키를 🔑 카드에 넣으세요.

Q: 환자 목소리가 안 잡혀요

거의 항상 Windows 기본 입력 장치가 노트북 내장 마이크로 잡혀 있는 경우입니다. 9장 체크리스트 3번.

Q: 환자 데이터가 저장되나요?

아니요. 이 앱은 아무것도 저장하지 않습니다 (11장). 다만 어느 AI 회사에 보내는지는 본인이 고르는 것이니 병원 정책에 맞는 회사만 체크하세요.

Q: 다른 선생님에게 주소를 알려주면 내 API 키가 새나요?

아닙니다. 키는 각자 PC 브라우저에만 저장됩니다. 서버가 없으니 어디로도 전송되지 않습니다. 단, 같은 PC·같은 브라우저를 공유하면 키도 공유되니 Chrome 프로필을 나누세요.

Q: PDF·Word 녹취록을 올리고 싶어요

파일을 열어 내용을 복사한 뒤 ⌨️ 탭에 붙여넣으세요. txt·csv로 저장한 파일은 📁 탭에서 바로 됩니다.

Q: 처방까지 자동으로 넣어 주나요?

아니요. SOAP의 P는 약 계열·검사·시술 같은 오더 수준까지만 쓰고, 처방은 EMR 처방창(약속처방 탭)에서 직접 입력합니다. EMR 처방창은 붙여넣기를 받지 않습니다.

Q: 설정을 다른 PC로 옮기려면?

🔑 카드 아래 📤 설정 내보내기 → 파일 저장 → 다른 PC에서 📥 설정 가져오기. 파일에 키가 들어 있으니 USB로 직접 옮기고 남에게 보내지 마세요.
